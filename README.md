## 2. Descripción del proyecto

Proyecto que permita a las personas descubrir espectáculos y actividades para disfrutar durante su tiempo libre.

Tiene como objetivo centralizar la información de distintas actividades y facilitar la búsqueda de opciones de entretenimiento según gustos de cada usuario.

Las categorías son, cine, teatro, conciertos entre otras.

Para cada actividad se muestra la siguiente información:

- Nombre y descripción de la actividad.
- Horario.
- Lugar.
- Costo.
- Categoría.

Además, la aplicación permite configuración de acuerdo con los gustos de cada usuario.

## 3. Alcance del producto

El alcance se establece a partir de la investigación del problema y del relevamiento de necesidades de usuarios reales.

Alcance:

1. Proporcionar información sobre espectáculos y actividades.
2. Organizar las actividades en distintas categorías.
3. Mostrar información sobre horario, lugar y costo.
4. Permitir la configuración de la aplicación según los gustos de cada persona.

## 6. Control de versiones

Se utilizará GitHub como repositorio central del proyecto.

La rama `main` contendrá las versiones integradas del trabajo y será utilizada como version de porduccion.

Como estrategia de trabajo, es la siguiente:

1. Crear una rama para cada funcionalidad o correccion de bug.
2. Realizar los cambios en la rama correspondiente.
3. Testear dicha funcionalidad
5. Integrar los cambios a `main`.
